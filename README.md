# Rainbow Ghost Rescue

A pixel-art adventure for kids: free the rainbow ghosts, save your house and stop the Shadow King.

Play it at https://clevelandbuilders-cmyk.github.io/rainbow-ghost-rescue/

On an Android tablet, open the link in Chrome, then use the menu and choose "Add to Home screen" (or "Install app") to install it. It works offline after the first visit.

Updates to the game appear at the same link.
